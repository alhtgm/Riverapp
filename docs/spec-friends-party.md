# River 新機能仕様：フレンド・パーティー（v2）

> **実装時に決まった変更（2026-10）** — 本文より優先する
> - 4章 公開範囲：「パーティー内」は**参加者が選んだパーティーのメンバーだけ**に見せる。「フレンドまで」は選んだパーティー＋参加者のいずれかのフレンド。新たに「**公開しない**」（参加者のみ）を追加。新しい講義は、作成者が所属するすべてのパーティーを選んだ「パーティー内」で始まる。
> - 7章 進捗の名前：個人設定「進捗を名前で表示しない」は設けず、**参加者には参加者全員の名前を表示**する（参加者以外には人数のみ）。ブロック関係にある人の名前は伏せる。ステータスは未着手／進行中／完了／提出済みの4つすべてについて表示する。
> - 8章 除外の解除投票を実装（成立すると「退出済み」に戻り、再び参加・申請できる）。
> - 3章 パーティー招待はフレンドのみ。除外された人は招待コードでも戻れない。
> - 大学（学校ドメイン）による所属判定は任意になった（アカウント設定から登録）。どの機能の閲覧範囲にも影響しない。

## 0. コンセプト

公開テンプレート機能は廃止し、身内だけで講義と課題を共有する仕組みに置き換える。セットログのように閉じた輪の中で「一緒に進めている」「誰が終わったか」が見えることで、身内感と課題を進める動機をつくる。

### 用語

| 用語 | 意味 |
|---|---|
| 参加者 | ある講義に参加しているユーザー |
| メンバー | あるパーティーに所属しているユーザー |
| 閲覧可能 | 4章の判定で講義が見える状態 |

### 上限値（定数として1か所で管理する）

| 項目 | 値 |
|---|---|
| パーティーの最大人数 | 20人 |
| 1ユーザーが所属できるパーティー数 | 10 |
| 1講義の最大参加者数 | 200人 |
| 招待コードの有効期限 | 1時間／24時間／7日から選択（既定：24時間） |
| 招待コードの使用回数上限 | 1／5／20回から選択（既定：5回） |
| 参加申請の自動失効 | 14日 |
| 除外投票の有効期間 | 7日 |

---

## 1. フレンド

- 申請 → 承認でフレンドになる。申請は**承認／拒否／取り下げ**ができる。
- フレンドはどちらからでも**解除**できる。解除しても相手に通知はしない。
- **ブロック**：ブロックした相手からのフレンド申請・パーティー招待は届かず、互いのプロフィールが見えなくなる。ブロックするとフレンド関係は解除される。ブロックされた側には通知しない。

## 2. プロフィール

- 各ユーザーは一意の**ユーザーID（@handle）**と表示名を持つ。
- **ユーザー検索はユーザーIDの完全一致のみ**とする（表示名での部分一致検索はしない。なりすましや付きまといを防ぐため）。
- プロフィールには、表示名・ユーザーID・**閲覧者から見える講義**とその課題を表示する。
- 表示されている講義には、参加または参加申請ができる（5章の参加ボタン）。
- 自分をブロックしている相手のプロフィールは、検索結果に出ない。

## 3. パーティー

- 最大20人。1ユーザーは最大10個のパーティーに所属できる。
- メンバーは全員対等で、リーダーはいない。
- パーティー名は、メンバーなら誰でも変更できる（変更はログに残る）。
- 参加方法：
  - **フレンドからの招待**（招待された側が承諾すると参加）
  - **招待コード**：メンバーなら誰でも発行でき、有効期限と使用回数の上限を設定する。メンバーなら誰でも、どのコードでも**無効化**できる。
- **退出**：いつでも自分で退出できる。最後の1人が退出したパーティーはアーカイブされる。
- **メンバーの除外**：個人に除外の権限はない。代わりに**除外投票**で外す（8章）。

### パーティーのホーム画面

- メンバーが参加している講義のうち、**自分から閲覧可能なもの**を一覧で表示する。
- 講義ごとに、参加人数と、そのうちこのパーティーのメンバーの人数を表示する。
- ここから講義に参加または参加申請ができる（5章の参加ボタン）。
- メンバー一覧、招待コードの発行・無効化、退出、除外投票はここから行う。

## 4. 講義の公開範囲

公開範囲は**講義そのものの設定**であり、参加者なら誰でも変更できる。変更はログに残し、参加者に通知する。

| 公開範囲 | 見える人 |
|---|---|
| パーティー内 | 参加者のいずれかと同じパーティーに所属している人 |
| フレンドまで | 上記 ＋ 参加者のいずれかのフレンド |
| 全体 | 誰でも |

- 範囲は入れ子になっている（パーティー内 ⊂ フレンドまで ⊂ 全体）。
- 参加者自身は常に見える。
- ブロック関係は公開範囲より優先する（ブロックしている／されている相手が唯一の接点の場合、その相手経由では見えない）。
- 講義から除外された人には、公開範囲に関係なく参加ボタンを表示しない（5章）。
- 新しく作った講義の既定値は「パーティー内」。

## 5. 講義への参加

### 講義の作成

- 項目：講義名（必須）、年度（必須）、学期（前期／後期／通年／その他、必須）、担当教員（任意）。
- 作成時に、**自分から閲覧可能な講義のうち、年度と学期が同じで講義名が似ているもの**があれば「既存の講義に参加しますか？」と候補を提示する（講義名の比較は、全角／半角・空白・大文字／小文字の違いを正規化してから行う）。
- 作成者は最初の参加者になるだけで、特別な権限は持たない。

### 参加

- 参加の単位は講義。参加すると、その講義の課題がすべて自分のRiverに入る（あとから追加された課題も含む）。
- 参加の入口：メンバーのプロフィール、パーティーのホーム画面。

### 参加ボタンの表示（どちらの入口でも共通）

| 状態 | 表示 | 押したときの動作 |
|---|---|---|
| 未参加・申請オフ | 参加する | すぐ参加する |
| 未参加・申請オン | 参加申請 | 申請中になる |
| 申請中 | 申請中 | 申請を取り下げる（確認あり） |
| 参加済み | 参加中 | 講義の画面を開く |
| 除外済み | （表示しない） | — |

### 参加申請の設定

- 講義ごとにオン／オフを設定できる（公開範囲とは別の設定）。
- 参加者なら誰でも切り替えられ、変更はログに残る。
- **公開範囲が「全体」の間は、申請オンに固定する**（オフにできない）。全体公開に変更すると自動でオンになり、その旨を表示する。
- 申請は、参加者なら誰でも**承認または却下**できる。
- 申請が届いたら参加者全員にアプリ内通知を送る。14日間誰も対応しなければ自動で失効する。

### 退出

- 参加者はいつでも退出できる。
- 退出すると、その講義の課題は自分のRiverから消える。自分の進捗データは非表示にして保持し、再参加したときに復元する。
- 参加者が0人になった講義はアーカイブされ、誰からも見えなくなる（削除はしない）。

## 6. 課題の共同管理

### 共有する項目と個人ごとの項目

| 区分 | 項目 | 編集 |
|---|---|---|
| 共有（全参加者に反映） | 課題名、締切、説明、関連URL | 参加者なら誰でも |
| 個人ごと | 進捗（未着手／取り組み中／完了）、作業予定期間（ガントのバーの開始・終了）、個人メモ | 本人のみ |

- 誰かが課題を追加・編集すると、全参加者に反映される。
- **締切が変更されたら参加者全員に通知する**。
- 新しく参加した人や、新しく追加された課題の作業予定期間は、未設定（締切だけが表示される状態）から始める。

### 削除と履歴

- 削除の前に確認ダイアログを出す。
- 削除は論理削除とし、参加者なら誰でも「削除済みの課題」から**復元**できる。
- 課題の追加・編集・削除・復元、講義の設定変更はすべて**操作履歴**に残し、講義の画面から参照できる（誰が・いつ・何を・変更前と変更後の値）。

## 7. 進捗の相互確認

- 講義・課題ごとに、**取り組み中の人数**と**完了した人数**を表示する。これは講義を閲覧できる人なら誰にでも見える。
- **名前の表示**：
  - 名前が見えるのは、その講義の参加者だけ。
  - 参加者から見て、自分のフレンドまたは同じパーティーのメンバーである人は、名前（とアイコン）を表示する。それ以外の人は「ほか○人」とまとめて表示する。
  - 表示形式：課題ごとに「完了」「取り組み中」に分けてアイコンを並べる（多い場合は先頭数人＋「ほか○人」）。
- **個人設定「進捗を名前で表示しない」**：オンにすると、人数には数えられるが、名前は誰にも表示されない。

## 8. 除外投票（荒らし対策）

講義・パーティーのどちらにも、個人に除外の権限はない。代わりに投票で外す。

- 参加者（メンバー）なら誰でも、ほかの1人に対して除外投票を始められる。
- 対象者を除く参加者（メンバー）の**過半数**（端数は切り上げ）が賛成した時点で除外が成立する。
- 投票は7日で失効する。対象者には投票中であることを表示しない。
- 除外された人は、その講義（パーティー）に再び参加・申請できない。除外は、再度の投票で解除できる。
- 投票の開始・成立・失効は履歴に残す。

## 9. 通知（アプリ内のみ）

次のときに通知する：フレンド申請を受けた／承認された、パーティーに招待された、参加している講義に参加申請が届いた、自分の参加申請が承認・却下された、参加している講義の課題の締切が変わった、講義の公開範囲が変わった。

## 10. テンプレート機能の廃止

- テンプレートの公開・閲覧・利用に関わる画面、API、テーブルを削除する。
- テンプレートから取り込み済みの講義・課題は、ユーザー自身の講義・課題として残す。
- 既存の講義は、そのユーザーだけが参加している講義（公開範囲：パーティー内、申請：オン）に移行する。
